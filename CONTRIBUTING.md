# Contributing to SaberRig / Cómo contribuir a SaberRig

Thanks for your interest in SaberRig.  
Gracias por tu interés en SaberRig.

---

## English

### Who can do what

| Action                        | Who                          |
|-------------------------------|------------------------------|
| Open issues (bugs / ideas)    | Anyone                       |
| Suggest features              | Anyone                       |
| Open Pull Requests (code)     | **Not currently accepted**   |
| Merge code changes            | Maintainer only (@XDZR8)     |

SaberRig is currently maintained by a single developer.  
**External code contributions (Pull Requests) are not accepted at this time.**

You can still help a lot by reporting bugs and suggesting improvements.

### Reporting bugs

Before opening a new issue:

1. Make sure you are using the **latest release**.
2. Search existing issues to avoid duplicates.
3. Include as much of the following as possible:

| Information              | Example                          |
|--------------------------|----------------------------------|
| SaberRig version         | 1.0.5                            |
| Blender version          | 5.1.1 / 5.3.0                    |
| Operating system         | Windows 11 / macOS / Linux       |
| Selected profile         | Uma Musume, FGO Arcade, etc.     |
| Steps to reproduce       | Clear numbered steps             |
| Expected vs actual result| What should happen vs what happens |
| Console errors           | Relevant System Console messages |
| Screenshots              | Optional but very helpful        |

**Important:** Do **not** upload copyrighted game assets (models, armatures, textures, etc.).

### Suggesting features

Open an issue describing:

- What you would like to achieve  
- Why it would be useful  
- Any example or reference (if available)

Feature requests are welcome and will be considered according to project scope and available time.

### License

By interacting with the project you agree that any accepted contribution would be licensed under the same license as the project: **GNU GPL v3.0**.

## Español

### Quién puede hacer qué

| Acción                              | Quién                          |
|-------------------------------------|--------------------------------|
| Abrir incidencias (bugs / ideas)    | Cualquiera                     |
| Sugerir funciones                   | Cualquiera                     |
| Abrir Pull Requests (código)        | **No se aceptan actualmente**  |
| Fusionar cambios de código          | Solo el mantenedor (@XDZR8)    |

SaberRig es mantenido actualmente por un único desarrollador.  
**Por el momento no se aceptan contribuciones de código externas (Pull Requests).**

Aun así puedes ayudar mucho reportando errores y sugiriendo mejoras.

### Cómo reportar errores

Antes de abrir una nueva incidencia:

1. Comprueba que usas la **última versión** publicada.
2. Busca en las incidencias existentes para evitar duplicados.
3. Incluye la mayor cantidad posible de esta información:

| Información              | Ejemplo                          |
|--------------------------|----------------------------------|
| Versión de SaberRig      | 1.0.5                            |
| Versión de Blender       | 5.1.1 / 5.3.0                    |
| Sistema operativo        | Windows 11 / macOS / Linux       |
| Perfil seleccionado      | Uma Musume, FGO Arcade, etc.     |
| Pasos para reproducir    | Pasos claros y numerados         |
| Resultado esperado vs real | Qué debería pasar vs qué pasa  |
| Errores de consola       | Mensajes relevantes de la System Console |
| Capturas de pantalla     | Opcional pero muy útil           |

**Importante:** **No** subas recursos de videojuegos protegidos por derechos de autor.

### Sugerencias de funciones

Abre una incidencia y describe:

- Qué te gustaría conseguir  
- Por qué sería útil  
- Algún ejemplo o referencia (si la tienes)

Las sugerencias son bienvenidas y se valorarán según el alcance del proyecto y el tiempo disponible.

### Licencia

Al interactuar con el proyecto aceptas que cualquier contribución aceptada se licenciaría bajo la misma licencia del proyecto: **GNU GPL v3.0**.
